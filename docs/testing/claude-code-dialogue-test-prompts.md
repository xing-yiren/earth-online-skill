# Claude Code Dialogue Test Prompts

> 用于在 Claude Code 中手动测试地球 Online Skill 的真实对话体验。

## 基础闭环

依次输入：

```text
早安
```

期望：

- 记录晨间签到
- 输出今日副本
- 展示生存天数、连续早起、今日任务、积分等级

```text
我今天要整理项目计划
```

期望：

- 创建主线任务
- 返回任务名称、积分、频率、截止信息

```text
以后每天阅读30分钟
```

期望：

- 创建每日支线任务
- 表明会保留在每日副本里

```text
我现在还有什么任务
```

期望：

- 列出进行中的主线和支线

```text
项目计划整理完了
```

期望：

- 完成匹配任务
- 增加积分
- 更新成就统计
- 输出自然语言完成反馈

```text
今天结算一下
```

期望：

- 输出每日结算
- 展示完成数量、获得积分、待推进任务、当前等级

## 修改与取消任务

```text
把阅读30分钟改成阅读45分钟
```

期望：

- 调用 `update_task`
- 如果匹配不唯一，先让用户确认

```text
取消阅读45分钟这个任务
```

期望：

- 调用 `cancel_task`
- 取消后不再出现在进行中任务和晚间待推进里

```text
我现在还有什么任务
```

期望：

- 已取消任务不再出现

## 奖励兑换

```text
有什么奖励可以兑换
```

期望：

- 输出奖励目录
- 包含名称、积分消耗、说明

```text
我想兑换周末看电影
```

期望：

- 如果积分不足，说明还差多少
- 如果积分足够，要求确认兑换

```text
确认兑换
```

期望：

- 只有在上一轮已明确奖励且积分足够时，才调用 `redeem_reward(confirm=true)`
- 成功后扣积分并记录兑换历史

## 多候选确认

先创建两个相近任务：

```text
我今天要整理项目计划
```

```text
我今天要完善项目计划
```

然后输入：

```text
项目计划做完了
```

期望：

- 返回多候选
- Claude Code 不应猜测，应让用户选择具体任务

## 重复完成

```text
整理项目计划完成了
```

再次输入：

```text
整理项目计划完成了
```

期望：

- 一次性任务不能重复完成
- 不重复加分

## 晨间幂等

连续输入两次：

```text
早安
```

期望：

- 第二次晨间签到返回已记录
- 不重复增加早起 streak

## 晚间结算幂等

连续输入两次：

```text
今天结算一下
```

期望：

- 结算是只读聚合
- 两次结果一致，不修改状态

## 风格检查

回复应满足：

- 有游戏化体验，但不过度中二
- 关键节点有仪式感
- 失败场景给下一步建议
- 不把 JSON 原样展示给用户，除非用户明确要求看结构化数据
