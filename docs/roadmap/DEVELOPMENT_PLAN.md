## 阶段 3：对话体验打磨（基本完成）

### 3.1 晨间播报与晚间结算游戏化升级 ✅
- ~~`morning_renderer.py` 和 `settlement_renderer.py` 游戏化~~
- 已升级为**无限流小说系统**风格（`叮！亲爱的XX玩家`、`恭喜通过昨日生存关卡`）
- 已重构为**数据卡片架构**：渲染器输出 `[标签] key:value`，Claude 按风格规范自由组织语言

### 3.2 渲染器架构重构 ✅
- 6 个渲染器全部转为数据卡片格式
- SKILL.md 定义风格规范（世界观映射、语气节奏、输出要求）
- Claude 不再机械复制 message，而是按上下文自行发挥

### 3.3 全局 Skill 安装 ✅
- 全局 skill 安装到 `~/.claude/skills/earth-online-skill/SKILL.md`
- 数据目录 `~/.earth-online/data/` 跨项目共享
- 环境变量修复（`set` → inline bash 语法）

### 3.4 定时提醒 ✅
- 早间提醒：每天 08:57
- 晚间提醒：每天 22:07
- 限制：仅在 Claude Code 空闲时触发

### 3.5 其他优化 ✅
- `create_task` 参数名 `name` 明确文档
- `init_skill_profile` 增加晨间/晚间可选配置项
- 跨会话任务扫描：三级数据源（项目文件 / 会话对话 / 项目摘要）+ 质量评分
- 琐碎模式黑名单过滤
